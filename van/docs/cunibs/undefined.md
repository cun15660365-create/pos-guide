# 가맹점 관리비 수취 내역

{% hint style="info" %}
**※ DATA 업로드 : 당월11\~익월2일까지** <mark style="color:red;">**\*\*공휴일 상관없이 마감**</mark>

(기한내 미등록시 대행발행 불가하며, 나이스빌에 등록된 공동인증서 만료도 발행 불가함)

**※ CUN 대행기간 :** 익월3일\~6일까지 (DATA 업로드 불가능)

**※ 신협 직접발행 :** 익월7일\~10일까지 (DATA 업로드 후 파일 다운로드 받아 나이스빌 사이트에서 직접 발행 )
{% endhint %}

### ☑️ 가맹점 관리비 업로드(대행조합)

<details>

<summary><mark style="background-color:blue;"><strong>엑셀 파일 양식</strong></mark></summary>

**※ 오류가 포함된 엑셀파일은 닙스메뉴의 우측상단영역에 표시되며 데이터업로드가 불가능합니다.**\
**엑셀파일 확인 후 다시 등록하십시오.**

1. <mark style="color:red;">파일형식Excel97-2003 통합문서로 저장되어 있는지 확인</mark>
2. <mark style="color:red;">작성한 자료값 복사 후 새로운 시트에 붙여넣은 후 재업로드</mark>

<figure><img src="../.gitbook/assets/image (109).png" alt=""><figcaption></figcaption></figure>

</details>

<details>

<summary><mark style="background-color:blue;"><strong>조회 및 등록</strong></mark> </summary>

1\. 가맹점: \[2620] 가맹점관리비 수취내역 메뉴 선택\
2\. \[2621] 데이터 업로드 선택\
3\. 입금월, 조합코드 확인 후 조회\
4\. '엑셀업로드' 선택하여 파일 업로드\
5\. 정상데이터로 모든 데이터가 넘어갔는지 확인\
&#x20;<mark style="color:red;">\* 정상데이터에 '기등록'으로 업로드 되어있을 경우 정상적으로 업로드 된 파일입니다.</mark>

<figure><img src="../.gitbook/assets/image (110).png" alt=""><figcaption></figcaption></figure>

</details>

<details>

<summary><mark style="background-color:blue;"><strong>삭제</strong></mark></summary>

※ 등록된 데이터 중에 데이터가 잘못 되어서 재등록 할 때에는 개별삭제 할 수 없으며,\
일괄삭제를 해야 합니다. <mark style="color:red;">**(입금월 확인 후 삭제요망)**</mark>

<figure><img src="../.gitbook/assets/image (111).png" alt=""><figcaption></figcaption></figure>

</details>

### ☑️ 업로드가 안될 때

<details>

<summary><mark style="background-color:blue;"><strong>양식 확인 (Excel 97-2003 통합 문서)</strong></mark></summary>

조합코드, 순번, 입금일자, 사업자번호,입금금액

1. <mark style="color:red;">**빈공간 없이**</mark> 정확히 들어가 있는지 확인해주세요
2. 제대로 <mark style="color:red;">**양식에 맞게**</mark> 들어가 있는지 확인해주세요

<figure><img src="../.gitbook/assets/image (134).png" alt=""><figcaption></figcaption></figure>

</details>
