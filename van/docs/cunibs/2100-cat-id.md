# \[2100] CAT-ID 추가/ 기기변경

{% hint style="info" %}
단말기 등록/기기변경 하려고 하는데 찾는(추가하려는) 단말기 조회 안될 시\
\[5400] 대리점별 단말기 현황에서 해당 기기번호가 <mark style="color:red;">**"사용중" 혹은 "폐기" 상태인지 조회**</mark>해주세요.
{% endhint %}

{% hint style="info" %}
기기변경 시 변경할 단말기로 CAT-ID를 추가 생성했다가 기존 단말기 CAT-ID를 해지하는 방법으로 처리하시는 경우가 있는데, 아래와 같은 문제가 발생합니다.

1. 기존 CAT-ID로 받았던 승인을 단말기 취소할 수 없게 됨. 가맹점에서 카드사로 전화해야 취소 가능함.
2. 중복승인관리, 공동승인관리 여부가 기본값으로 변경됨 (기존에 해당 정보를 바꾸었다면 다시 정보변경 작성해야 하며, 가맹점 민원 발생 여지가 있음)
3. 카드사 가맹번호를 재등록해야 하며, 키인(Key-in) 정보가 초기화 됨
4. 해지된 CAT-ID에 중복승인, 공동승인 등 미처리 건이 남아있으면 CUNIBS에서 청구 불가. 전표매입으로만 청구 가능함.
5. CAT-ID 착오로 담당자가 해지된 CAT-ID로 다운로드를 받는 경우가 빈번함
6. 기타 다양한 문제가 발생 할 수 있으므로 꼭 "기기변경" 버튼을 눌러 처리 요망
{% endhint %}
