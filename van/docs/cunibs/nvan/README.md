# NVAN 이용계약서 업로드

{% hint style="info" %}
**NVAN** : 신협에서 수취해야 가맹점 VAN이용계약서, 임대 판매 계약서 작성, 전송 및 간편결제(카카오페이, 네이버페이, 토스페이, 제로페이, 페이프로, 페이코) 가맹을 지원하는 어플

**태블릿 단말기 권장 사양** : Android/ iOS , 9.7 inch 이상

**화면 비율** : 4:3 또는 16:10
