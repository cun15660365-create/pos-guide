<summary>카드 승인이 거절됩니다.</summary>

승인이 거절되면 CUNIBS \[3100] 거래내역조회에서 승인번호 부분 하이픈 ( - ) 을 클릭하여 카드사 거절인지 VAN사 거절인지, 거절사유는 무엇인지 확인해주세요

(카드사 거절은 해당 카드사로 가맹점 혹은 카드고객이 전화로 문의하여 사유 확인해야 함)

아래 주요 거절 사유를 참고하여주세요.

* **자가매출, 본인카드**: 대표자, 혹은 대표자 명의 가족카드 승인 불가
* **CALLISSUER = 카드사연락요망:** 카드사로 전화하셔야 사유를 알 수 있습니다.
* **미등록가맹점:** \[2100]가맹점 등록 수정에서 카드사 가맹번호가 정상인지 확인해주세요. ex) 해지된 CAT-ID, 카드사에서 가맹번호를 해지, BIZFast 가맹점신규 미완료, \[2100]가맹점 등록수정에 가맹번호 미등록 등
* **클린카드 사용불가:** 사용 가능 가맹점인지 카드사로 상담 (업종 제한)
* **제휴카드 가맹점 아님:** 해당 카드를 받으려면 가맹점에서 별도의 조건을 갖춰야 합니다 (업종 등) 카드사로 거절 사유 및 승인 받을 수 있는 조건 문의주세요.
* **할부개월 오류:** 카드사에서 신규 가맹 심사 시 가맹점이 받을 수 있는 최대 할부 개월 수를 지정합니다. 늘리고 싶으시다면 카드사 지역센터로 상담 해주세요.
* **IC카드처리오류 MS로 거래하세요=IC카드 제거 후 마그네틱 거래를 해주세요=IC카드 사용이 불가한 경우 좌측상단 리더기에 카드 윗면을 화살표 방향으로 긁어주세요.** 카드의 IC칩 인식이 안되는 경우입니다 (손상 등) 메시지 나온 상태에서 MSR에 카드 마그네틱 부분을 읽혀주세요. 이러한 거래를 폴백(Fall back) 거래라고 합니다. ※주의! 오류 메시지를 종료 버튼 눌러 없앤 다음 MSR부분에 마그네틱을 인식하면 안됨(다시 IC로 승인 요청됨) 꼭 메시지 나온 상태에서 진행. 단, 모든 카드에 위 메시지가 나온다면 단말기 센서쪽 문제일 수 있으니 as 진행해주세요.
* **카드를 홈에 통과시켜주세요:** BC카드 전화승인 등록을 시도하면 나오는 메시지입니다.  현재 NICE VAN사를 통한 전화 승인 청구는 어려우며, 압인전표 직접 매입을 유도해주세요. 자세한 내용은 CUNIBS 공지사항『전화승인 매입 업무 변경 안내의 건 (변경일정확정)』 참고해주세요.
* **키인 한도 초과:** 해당 가맹점이 받을 수 있는 키인 한도를 초과했거나, 키인이 불가능한 가맹점입니다. CUNIBS 공지사항 『카드번호 수동입력(KEY-IN승인)거래 업무 안내의 건』 참고해주세요.
* **카드를 제거해주세요:** 단말기에 해당 카드의 IC 정보가 없는 경우 발생합니다. 특수 6423-0)-1) IC정보 수동다운-전체다운 진행해주세요.  시간이 없을 경우 임시방편으로 폴백(Fall back)거래 진행해주세요
* **대행승인불가:** 카드사 전산오류(타임아웃) 발생하면 밴사에서 대행으로 승인을 내주는데, 신용카드는 가능하나 체크카드는 고객 통장에서 직접 인출을 할 수 없으므로 대행승인불가 메시지 발생하며 거래가 거절됩니다.

  ② 수정세금계산서 발급사유를 선택 후 하단의 ‘확인’ 버튼을 클릭합니다.\
  ③ 각 수정 사유에 따라 부(-)의 세금계산서가 자동으로 화면에 나타나며, 사유에 맞게 수정 후 상단의 ‘즉시발행’(<img src=".gitbook/assets/image (190).png" alt="" data-size="line">) 버튼을 클릭하여 ‘공동인증서 암호 입력절차’를 거쳐 최종  \
  발행업무를 완료합니다.
