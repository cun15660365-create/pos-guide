# 카드번호승인 설정(키인승인)

{% hint style="info" %}
&#x20;**키인승인이란?**

고객이 카드를 소지하고 있지 않거나, 원거리에서 카드번호로 결제 요청하는 경우 단말기에서 실물카드 없이 카드번호, 유효기간을 입력하여 결제하는 방식. 각 카드사의 키인(KEY-IN)승인 한도 내에서만 결제 가능, 특히 **현대, 하나 카드**는 가맹점에 키인 한도가 없는 경우 多. **카드사로 가맹점별 키인 한도 확인 必**
{% endhint %}

### ☑️ CUNIBS 설정 방법

\[2100] 가맹점 정보 등록수정 하단 카드사Tap에서 KEYIN체크 후 저장

### ☑️ 단말기 설정 방법

특수버튼-암호 6423-8번(부가기능1)-카드번호수동입력 “사용”으로 설정 (**NPC-1000, NPC-2000 기종은 부가기능 →4번 핫키설정 →7번키 Keyin승인으로 추가설정 필요)**

### ☑️ 단말기 결제 방법

메인화면에서 숫자7번-카드번호, 유효기간 입력-판매금액 입력-결제영수증 확인

### 자주 묻는 질문 Q\&A

<details>

<summary>키인 한도 초과 or 카드를 홈에 통과시켜주세요</summary>

해당 가맹점이 받을 수 있는 키인 한도를 초과했거나, 키인이 불가능한 가맹점입니다. 카드사 문의해주세

</details>

<details>

<summary>해외카드도 번호승인이 가능한가요?</summary>

해외카드 키인(KEY-IN)은  해외카드 매입사에 해외카드 KEY-IN 특약이 설정 되어있는지 확인 후 CUNIBS-위험관리-\[4500]정보변경관리-양식별등록-해외카드KEY-IN확약서 접수해주세요.

\*\* 해외카드 매입사는 “신한(구LG)카드”로 지정되어 있지만, 신한(구LG)카드 외 타카드사가 해외카드 매입사로 지정하려면 \[2100] 가맹점등록수정 – 매입사강제지정 – VISA, MASTER, JCB 체크 – 해외카드 매입사로 지정할 카드,사 선택 – 저장

단, 해당 카드사와 해외카드 KEY-IN 특약이 되어있어야 함

</details>

<details>

<summary>롯데카드 키인승인이 안됩니다</summary>

롯데카드 해킹 사태 관련 롯데카드에서 임의로 가맹점 키인 거래를 제한하고 있으며, 해당 가맹점 기준은 다음과 같습니다.

1\) '25년 1월\~8월 키인 거래 무실적 가맹점 키인 거래 제한

2\) '25년 9월 18일부터 개설된 신규 가맹점 키인 한도 '0' 원 적용

</details>
