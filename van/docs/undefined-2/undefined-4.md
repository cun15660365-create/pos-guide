# 무선단말기 주요 기능

{% hint style="info" %}
CUNIBS \[5200] 무선단말기 개통 및 관리 화면에서 개통이력 조회 가능
{% endhint %}

### ☑️ 절전기능 설정 방법

* NF-1000/1100 : 특수버튼 → 1234 → 2. 절전모드설정 → 1. 절전기능설정 → 1)자동전원끄기/2)사용안함
* ZA-1000K : 특수버튼 → 1234 → 1. 절전모드 → 0)절전모드/1)자동전원끄기/2)사용안함
* NPM-2000S : 정정(특수기능) → 6. 단말기설정 → 16. 절전기능선택 → 1)슬립모드/2)자동전원끄기/3)사용안함

***

### ☑️ 개통번호/유심번호 확인 방법

* NF-1000/1100 : 특수버튼 → 4616 → 전화번호확인 특수버튼 → 9778 → 유심번호확인
* ZA-1000K : 기타(000버튼) → 3. 모뎀정보 → 유심번호, 전화번호 확인
* NPM-2000S : 기타(000버튼) → 6. 모뎀정보 → 유심번호, 전화번호 확인

***

### ☑️ 용지 설정 방법

* NF-1000/1100 : 기타(000버튼) → 3. 용지 → 0)출력매수설정/1)인쇄농도설정
* ZA-1000K : 부가기능(7번 버튼) → 3. 용지설정 → 1)출력매수설정/2)인쇄농도설정
* NPM-2000S : 부가(00버튼) → 3. 용지설정 → 1)출력매수설정/4)인쇄농도설정

***
