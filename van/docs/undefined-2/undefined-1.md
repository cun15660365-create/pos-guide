# 부가세/봉사료/면세 설정

💡 _**단말기에서 설정한 부가세 및 신면세과세 정보는 단말기 영수증과 CUNIBS에는 반영되지만,**_

_**실제 국세청 매출정보에는 반영되지 않는 참고용 자료입니다.**_

_**(ex 면세 사업자의 경우 부가세 “사용” 설정해도 세금 부과되지 않음)**_

* _**면세 가맹점의 경우 부가세 설정 메뉴가 아닌 “신면세과세“ 기능으로 사용하시기 바랍니다.**_
* _**봉사료는 실제 세금신고에 반영되기 때문에 신중하게 설정해야함**_&#x20;
