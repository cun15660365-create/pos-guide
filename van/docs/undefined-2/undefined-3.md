# 용지 오류 처리/ 재출력 방법

<details>

<summary><strong>용지 오류 처리 방법</strong></summary>

1. **영수증 글씨가 흐리거나 백지로 출력되는 경우**

비닐포장 미개봉한 새 용지로 교체 테스트\
프린터 커버 열고 먼지/이물질 등 제거 청소\
전원 아답터 교체 테스트\
전원 아답터 멀티탭이 아닌 원콘센트에 옮겨서 테스트\
그래도 동일시 단말기와 아답터 같이 AS



2. **용지가 걸리거나 아예 출력되지 않는 경우**

프린터 커버 열어서 육안상으로 보이는 결함이 있는지 H/W확인\
프린터 롤러 끝 톱니바퀴가 깨지지 않았는지 확인\
용지 방향을 맞게 넣었는지 확인\
용지를 3cm정도 빼고 프린터 커버 닫은 후 2번 용지설정-용지맞춤 테스트

</details>

<details>

<summary><strong>용지 재출력(재인쇄) 방법</strong></summary>



1. **재인쇄 기능은 마지막 거래만 가능합니다 (입력버튼**)

전표가 꼭 필요한 경우 해당 승인 건 취소 후 재승인 방법을 권장합니다



2. **MIT-3000, MIT-3100, MIT-4000, MIT-7000**　

000버튼→2번→카드 삽입/날짜/승인번호 넣으면 신용승인,취소 거래 확인 및 재인쇄



3. **NC-8000, NF-1100, ZA-1000K**

메인화면 → 입력버튼→ 이전거래 재인쇄 → 카드번호 or카드삽입/날짜/승인번호 넣으면&#x20;

신용승인,취소 거래 확인 및 재인쇄



4. **NC-7000**

: 입력\[재인쇄]→ 2번 이전거래 재인쇄 → 0번 이전 신용거래 재인쇄 → 카드 삽입&#x20;

: 입력\[재인쇄]→ 2번 이전거래 재인쇄 → 1번 이전 현금거래 재인쇄 → 소득,지출,자진 中 택1→ 번호입력



\*\*단, 모든단말기재인쇄는 제한적으로 가능합니다.&#x20;

(단말기 내부 메모리에서 지워진 신용데이터는 재인쇄 안됨 - 재다이얼, 초기화 등)

※ 서명 인쇄 안됨. “재인쇄전표” 문구 표기됨

</details>
