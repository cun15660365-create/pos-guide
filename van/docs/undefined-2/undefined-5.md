# 단말기 다중사업자 다운로드 방법

{% hint style="info" %}
**\[문화비소득공제] 문화비 소득공제 신청 관련 매뉴얼은**\
<mark style="color:$danger;">**CUNIBS \[8100] 공지사항 글번호 27978 참고**</mark>
{% endhint %}

### ☑️ 1. CUNIBS \[2100] 원장 가맹점 등록

1. 메인 사업장 \[2100]원장에 사용할 기기 등록 (메인,서브구분은 조합이 원하는대로 지정)
2. 서브 사업장 \[2100] 원장을 모바일 CAT-ID로 등록 (서브사업장은 9개까지 가능)

***

### ☑️ 2. 단말기 펌웨어 업그레이드 번호

다중사업자용 펌웨어 번호

MIT-3000 (560007), MIT-4000 (003001) NF-1100S (840004) , NF-2100S (980001) , NPM-2000S (001)

***

### ☑️3. 다중 단말기 설정

NC-7000, NC-8000, ZA-1000K 설정방법: 특수→2020 →다중사업자설정 NPC-1000. NPC-2000, NPM-2000S : 특수 → 관리자→ 6423 →9.부가기능2 →다중사업자설정

***

### ☑️ 4. 단말기 다운로드 방법

1. 6423 – 0 – 0 가맹점다운로드를 메인사업장으로 진행(일반단말기와 동일)
2. 6423 – 0 – 2 다중 다운로드(1\~9까지 번호 선택 후 다운가능)
3. 2\)번을서브가맹점수만큼반복함
4. 단말기 다운로드 (상세)

***

### ☑️ 5. 단말기 사용 방법

1. 메인 가맹점: 일반 가맹점과 동일 (카드넣고 금액넣고 승인, 취소 누르고 취소, 현금누르고 현금영수증)
2. 서브 가맹점: 초기화면에서 숫자키 1\~9번 누르고 결제 (어느 가맹점으로 결제/취소할지)

<figure><img src="../.gitbook/assets/image (166).png" alt=""><figcaption></figcaption></figure>

***

### ☑️ 특이사항

1. 서브 가맹점은 신용거래, 현금거래만 가능 (기타 부가기능 미지원)
2. 금융거래, 전화승인거래, 단말기정산은 메인 가맹점만 가능
3. 기존 일반버전에서 1번\~ 3번 버튼을 누르고 사용하는 조회, 용지설정, 등록메뉴는 0번 누르고 사용
4. 기존 일반버전에서 4번\~ 0번 버튼을 누르고 사용하는 메뉴는 지원되지 않음

### &#x20;☑️ 가맹점 정보 확인 방법

1. 메인가맹점 (특수기능 1234-1번)

* 일반 버전 단말기와 동일

2. 서브가맹점 (특수기능 1234-3번-3번)

* 메뉴 진입 후 각 서브 가맹점의 핫키로 사용하는 번호 입력 후 해당 가맹점 정보 확인
