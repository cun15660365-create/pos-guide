# 카드/현금영수증 승인 및 취소 방법

💡 **신용카드 승인 방법**

카드 삽입 → 판매금액 → (할부개월) → (서명) → 정상 승인 전표 출력&#x20;

💡 **신용카드 취소 방법**

<details open>

<summary>마지막 거래 취소 (직전취소)</summary>

취소 → 0) 직전취소 → 입력 → 카드 삽입 → 승인내역 확인 → 입력 → 정상 취소 전표 출력

</details>

<details open>

<summary>마지막 이전 거래 취소 (신용반품취소)</summary>

취소 → 2) 신용반품취소 → 카드 삽입 → 원거래매출일자 입력 → 원거래승인번호 입력 → 거래총액&#x20;

→ 승인내역 확인 후 입력 → 정상 취소 전표 출력

※ 원거래승인번호 확인방법: 영수증, 혹은 \[3100] 거래내역조회에서 확인

</details>

💡 **현금영수증 승인/취소 방법**

<details open>

<summary>소비자 소득공제</summary>

* 승인: 현금 → 1) 소비자소득공제 → 개인정보입력 → 금액 입력
* 취소: 취소 → 1) 현금영수증취소 → 1) 소비자소득공제 → 개인정보입력 → 취소사유 입력&#x20;

&#x20;              → 원거래승인번호(0으로 시작하는 9자리) 입력 → 원거래매출일자 입력 → 금액 입력

</details>

<details open>

<summary>사업자지출증빙</summary>

* 승인: 현금 → 2) 사업자지출증빙 → 사업자번호 입력 → 금액 입력
* 취소: 취소 → 1) 현금영수증취 소→ 2) 사업자지출증빙 → 사업자번호 입력 → 취소사유 입력

&#x20;              → 원거래승인번호 입력(0으로 시작하는 9자리) → 원거래매출일자 입력 → 금액 입력

</details>

<details open>

<summary>자진발급</summary>

* 승인 : 현금 → 0) 자진발급승인 → 금액 입력
* 취소: 취소 → 1) 현금영수증취소 0) 자진발급취소 → 취소사유 입력 → 원거래승인번호 입력

&#x20;              → 원거래매출일자 입력 → 금액 입력

※ 원거래승인번호 확인방법: 영수증만 가능. \[3100] 거래내역조회에서 확인불가

</details>
