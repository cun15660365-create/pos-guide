# 제신고 서류

**※ 내국인 여권 첨부 시  초본 첨부 필수**\
&#x20;\- (구)여권 + 초본(실명번호 뒷자리 마스킹 필수)\
&#x20;\- (신)여권 + 여권정보증명서 +초본(실명번호 뒷자리 마스킹 필수)

**※ 법인 등기부등본 첨부 기준**\
&#x20;**-** 법인등기부등본 하단 발급확인번호가 상인할 경우 - 반려됨\
&#x20;\- 법인등기부등본은 일부증명서는 불가. 전부증명서만 허용

**※ 대리인 신청 시 : 대리인 신분증+신청서 작성 위임장+\[개인사업자 : 사업자용 공동인증서 전자서명]**

**※ 법인소유 지배자확인서 (2026년 1월22일 시행)**\
&#x20;**-** 법인가맹점(사업자번호 80,89 포함)의 아래 정보 변경 시 필수 제출\
&#x20;\- 대표자변경(교체, 개명, 실명번호 수정), 상호명 변경, 공동대표 추가\
&#x20;\- 제외대상: 관련 법령에 따른 ‘실제소유자 확인 생략 대상’인 경우 제출 불필요 (농협카드도 제출불필요)
