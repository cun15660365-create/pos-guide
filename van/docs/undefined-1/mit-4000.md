# MIT-4000 설치 동영상

💡 [<mark style="color:$info;">**설치 동영상으로 이동**</mark>](https://www.youtube.com/watch?v=KpzzigezTnw) 📽️

<details>

<summary>MIT-4000 (NPS-100N 패키지) 설치방법</summary>

가맹점 환경에 따라 랜선, 공유기, 전화선(박스에 포함됨) 등 추가

1.준비물: 단말기(본체, 전원아답터, 멀티패드, 멀티패드 케이블, 전표

1. 설치 순서: 전원 아답터 연결 → 용지 장착 → 랜선 (& 전화선) 연결 → 멀티패드 연결 → 단말기 설정
2. 단말기 설정방법

&#x20;<i class="fa-circle-1">:circle-1:</i> 특수기능 2187-1  메모리초기화 (중고단말기의 경우에만 진행. 예전 가맹점 정보 삭제하는 작업)

&#x20;<i class="fa-circle-2">:circle-2:</i> 특수기능 1234-2 전송선로 선택 (0 일반전화선 or 3 이더넷)

&#x20;<i class="fa-circle-3">:circle-3:</i> 특수기능 6423-0 가맹점 다운로드

&#x20;    cat-id+001(\[2100]화면에서 확인), 담당자 휴대폰번호, 사업자번호, 인증번호(휴대폰 문자 확인)

&#x20;<i class="fa-circle-4">:circle-4:</i> 특수기능 6423-9 서명패드 사용 설정 – 속도 115200(서명패드는 38400) - NFC멀티패드 사용여부– 사용 – 멀티리더기 연동포트 - 핀패드 6423-9 paypro설정 - 멀티패드

&#x20;      (MIT 단말기 한정: 메인에서 3번 - 3 SafeKey다운)

&#x20;<i class="fa-circle-5">:circle-5:</i> 부가설정(선택사항)

&#x20;   ㄱ.  봉사료: 6423-8 봉사료 사용여부 (미사용/사용) – (자동산출/수동입력)

&#x20;     –봉사료세금포함여부 (포함/비포함) - 봉사료 % 설정

&#x20;   ex) 봉사료 포함 여부를 포함 설정 시 1000원 누르면 1000원만 결제됨

&#x20;         미포함 설정 시 1000원 누르면 1100원 결제됨

&#x20;   ㄴ.  신면세과세: 6423-9 신면세과세 사용여부

&#x20;     -면세+과세: 금액을 면세, 과세 따로 2번 물어봄

&#x20;     (주로 약국이나 정육식당 등 면세품목과 과세품목을 함께 판매하는 가맹점에서 사용)

&#x20;     -면세단독사용: 면세로만 결제됨 (면세 가맹점에서 사용)

&#x20;   ㄷ.  금융기능: 특수기능 0048 - 0 금융 다운로드 - 통합단말에서 모카드 등록

&#x20;   계좌이체나 잔액조회 등 금융 업무를 단말기에서 실행. 국선(일반전화선)으로만 가능

※ 부가세는 영수증과 CUNIBS에만 반영되는 수치이고, 실제 세금신고와 연관 없는 “참고용“ 자료임

※ 봉사료는 실제 세금신고와 연관있기 때문에 신중하게 설정해야 함!

<i class="fa-circle-6">:circle-6:</i> 승인테스트: 신용 1004원, 현금 1991원. **현금은 테스트 금액 제외하고 다른 금액으로**

&#x20;    **꼭 한 번은 승인**해야 국세청으로 현금영수증 가맹점 등록됨.

&#x20;    **생략 할 시 가맹점으로 가산세 발생 위험**

<i class="fa-circle-7">:circle-7:</i> 가맹점에서 AS, 전표수급 등으로 연락 할 수 있는 신협 VAN 담당자 명함 혹은 연락처 남기기
