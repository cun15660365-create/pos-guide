<summary>NPC단말기 금융 설정 방법</summary>

1. 특수 - 7번 전용가맹점설정 - 4번 신협 - 사용 - 2번 금융인증&#x20;

&#x20;   → 사용인증 전표 올라오며 통합단말에서 금융ID 생성되는지 확인

&#x20;   → 통합단말에서 카드번호 버튼 눌러 조합에서 입력 처리

2. 특수 - 7번 전용가맹점설정 - 4번 신협 - 사용 - 1번 가맹점 다운로드
3. 단말기가 자동으로 재부팅됨
4. 부가기능 - 핫키설정 - 3번키 신협설정
5. 3번 누르면 계좌이체/잔액조회/이체결과조회/거래내역인쇄 사용 가능합니다

</details>

<details>

<summary>NC-8000P 단말기 금융 설정 방법</summary>

1. 특수 - 2187 - TMS 업그레이드 (번호: 038001)
2. 특수 - 2187 - 메모리초기화
3. 특수 - 2020 - 신협 모드로 변경
4. 특수 - 6423 - 가맹점 다운로드
5. 특수 - 0048 금융다운로드 (입력버튼만 눌러주세요) - 다운로드 표 출력
6. 통합단말에서 모카드 등록
7. 사용 시 Paypro버튼 (0.Paypro 1.계좌이체 2.잔액조회 3.이체결과조회 4.거래내역조회)

</details>
