{% tab title="고정IP 설정" %}


특수기능-암호1234-2)전송선로선택 - 3)이더넷 - 1)고정IP - IP/ 서브넷마스크/ 게이트웨이 입력

(IP주소 입력시 .(점)은 입력 하지 않으며, 0을 앞에 넣어 3자리로 맞춰야함.

예) 192.168.0.23일 경우 → 192 168 000 023 으로 입력)

※ 고정 IP 확인 방법: PC시작버튼-보조프로그램-명령프롬프트-IPCONFIG 입력하여 확인

※ PC에서 확인한 고정IP를 그대로 넣으면 IP 충돌 나므로 IP의 마지막 자리를 다르게 입력 (1\~255 사이로)
