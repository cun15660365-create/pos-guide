<summary>앱포스 카메라 결제 방법</summary>

**1.앱포스(AppPOS) 카메라 결제란?**

* 카메라결제는 실물카드를 촬영하고 카드정보를 인식하여 결제하는 방법입니다.

**2.카메라 결제 방법**

* 결제 금액 입력 - 결제수단 선택 (카메라 결제) - 실물카드 정보 인식 - 카드정보 확인 - 결제 승인

<details>

<summary>모바일 결제기 리더기 설정이 안됩니다</summary>

1. 휴대폰에 다른 블루투스 기기가 연결되어있는지 확인
2. 리더기 설정 시 다른 모델명으로 선택하지 않았는지 확인
3. 휴대폰"위치"정보 켜고나서 시도
4. 어플 재설치
5. 네트워크 초기화 진행
6. 다른 휴대폰으로 테스트
7. 위 조치사항으로 해결이 안되면 A/S 진행

</details>
